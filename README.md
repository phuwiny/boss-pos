# Boss POS

เว็บแอปบริหารข้อมูลสินค้าและดูยอดขายรายวันสำหรับร้านค้าขนาดกลาง — HTML/CSS/JS ล้วน ไม่ต้อง build ไม่มี backend

## ฟีเจอร์
- **ยอดขาย**: เลือกวันที่ ดูยอดรวม/จำนวนบิล/ชิ้น/กำไรขั้นต้น, กราฟรายชั่วโมง, แนวโน้ม 7 วัน, สินค้าขายดี, รายการบิล (ยกเลิกบิลแล้วคืนสต็อก), แจ้งเตือนสินค้าใกล้หมด
- **ขาย**: ค้นหา/แตะสินค้าใส่ตะกร้า ตัดสต็อกอัตโนมัติ ห้ามขายเกินสต็อก
- **สินค้า**: เพิ่ม/แก้ไข/ลบ, ค้นหา, กรองหมวดหมู่, ตรวจ SKU ซ้ำ
- **ตั้งค่า**: สำรอง/นำเข้า JSON, ส่งออก CSV (UTF-8 BOM เปิดภาษาไทยใน Excel ได้), รีเซ็ตข้อมูลตัวอย่าง

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ (แยกตามเครื่อง/เบราว์เซอร์) — ควรสำรอง JSON เป็นระยะ

## เผยแพร่ด้วย GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → เลือก branch หลัก และโฟลเดอร์ `/ (root)`
ทุกพาธเป็น relative จึงทำงานได้ที่ `https://<user>.github.io/boss-pos/`

## รันในเครื่อง / ทดสอบ
```
python3 -m http.server 8000      # เปิด http://localhost:8000
node tests/smoke.mjs             # ต้องมี playwright
```
